# Developer Experience Metrics Dashboard

Full-stack adoption dashboard measuring platform feature usage. React/TypeScript frontend + Python backend + PostgreSQL data collection.

## Setup
```bash
npm install
npm run build

pip install -r backend/requirements.txt
```

## Features
- Track feature adoption across users
- Display usage trends per feature
- Recommend features to improve or retire
- Real-time metrics collection

## Stack
- **Frontend**: React + TypeScript
- **Backend**: Python + PostgreSQL
- **Metrics**: Event-based collection, adoption scoring

## Example
See which features are gaining traction and which to sunset based on actual usage patterns.
